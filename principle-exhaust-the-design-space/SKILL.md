# Exhaust the Design Space

Apply this skill only when the user requests it or another active skill routes
to it.

## When this applies

- A novel UI interaction or architectural decision has no precedent in the
  codebase.
- A product design decision depends on how the result feels, not on logic.

## Procedure

1. Build 2-3 competing prototypes.
2. Compare the prototypes side by side.
3. Commit to one design only after the comparison.

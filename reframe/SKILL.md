Apply this skill only when the user requests it or another active skill routes
to it.

Teach the operator the expert words for what they are building. Start from
their own files, code, and description, not from a summary.

## Procedure

1. Give 8 to 12 terms, ranked by how much each would change what gets built.
   For each term, give:
   - the word and its meaning in one plain sentence
   - the part of their description that it names
   - one real project, paper, or system that uses it that way, with a link
   - what it lets them ask an agent for
2. Pick 2 or 3 neighbouring fields that solved the same shape of problem under
   other names. For each field, say what carries over, where the analogy
   breaks, and which terms come back.
3. Name what they did not mention but should care about.
4. Rewrite their description with the new words.

## Quality bar

Open every link and confirm that it uses the term that way. Cut any citation
that you cannot confirm. Do not pad.

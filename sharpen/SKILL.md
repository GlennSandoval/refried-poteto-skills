Apply this skill only when the user requests it or another active skill routes
to it.

The user wants a deeper version of the task, not a bigger one.

## Analyse the task

Before you rewrite the task, do these four things:

1. Say what a top professional in this field would do here that the user is not
   asking for.
2. Name the rawest material that the professional would start from, instead of
   what has already been digested for the user.
3. Name the specific methods and tools that the professional would use.
4. Say what, other than you or the user, would show that the result is right.

## Rewrite the prompt

Rewrite the user's prompt to ask for exactly that.

In the rewritten prompt, ask the agent to prototype any choice that an
experiment can settle. Ask the agent to recommend an option based on what it
observed. Leave to the user any product or preference choice that no experiment
can settle.
